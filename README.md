# Veylora

**Autonomous Business Process Optimization using Process Mining, Causal
Inference, and Tool-Using AI Agents**

Veylora is a local-first business process intelligence and optimization
research prototype. It analyses historical event logs, identifies
process patterns and candidate improvement opportunities, evaluates
predictive models, and uses controlled synthetic experiments to
investigate possible interventions.

> **Research-use notice:** Veylora is a local development and portfolio
> prototype. It is not certified for production, regulated
> decision-making, or use with live customer data. It does not establish
> legal or regulatory compliance, verified operational savings, or
> causal impact in the historical process.

## Core capabilities

The Streamlit application currently includes eight workspaces:

1.  **Overview** --- case and event summary metrics.
2.  **Process Explorer** --- activity frequencies, transitions,
    variants, and lifecycle patterns.
3.  **Predictive Evaluation** --- duration and acceptance model
    evaluation with baseline comparisons and limitations.
4.  **Opportunity Register** --- historical evidence used to screen
    candidate process improvements.
5.  **Scenario Lab** --- hypothetical scenario calculations with
    explicit assumptions.
6.  **Evidence & Governance** --- artifact availability, definitions,
    evidence boundaries, and governance information.
7.  **AI Assistant** --- evidence-oriented analytical assistance, with
    optional local language-model integration.
8.  **Autonomous Optimization** --- adaptive rule-based selection and
    execution of registered analytical tools, synthetic experiment
    evaluation, candidate ranking, and an auditable recommendation.

The optimization agent uses a defined allow-list of analytical tools. It
does not execute operational business changes or arbitrary shell/code
supplied by a user.

## Analytical boundaries

Veylora deliberately separates three evidence types:

-   **Historical observations:** descriptive analysis of the BPI
    Challenge 2017 loan-application event log.
-   **Predictive evaluation:** exploratory model results compared with
    baselines. Current recorded results are weak and should not be used
    for operational decisions.
-   **Synthetic experiments:** randomized treatment-control experiments
    generated by the local simulator under configurable assumptions.
    Their effects are synthetic estimates, not measured effects in the
    historical process.

The historical causal assessment currently reports `not_identified`.
Historical transition gaps and outcome associations must not be
described as causal effects.

The field `duration_hours` represents elapsed time between the first and
last recorded event for a case. It is not active handling time, staff
working time, or verified queue time.

## Dataset

The current working analytical dataset is recorded as containing:

-   1,592 historical applications.
-   71,397 event records.
-   23 configured analytical artifacts.

These figures describe the current working copy and must be revalidated
against the exact input version before publication. The project uses the
BPI Challenge 2017 event log; review the dataset's official terms before

## Local setup --- Windows PowerShell

Run commands from the project root:

``` powershell
cd D:\intern\Veylora

# Activate the existing virtual environment
.\.venv\Scripts\Activate.ps1

# Install project dependencies if required
python -m pip install -r requirements.txt

# Run automated tests
python -m pytest -q

# Launch the application
.\start_veylora.bat
```

Alternatively, launch Streamlit directly:

``` powershell
python -m streamlit run app.py
```

Keep the terminal running while using the application. Stop the local
server with `Ctrl+C`.

## Limitations and responsible use

-   Do not use Veylora to approve, reject, price, or otherwise make
    decisions about real loan applicants.
-   Do not treat weak predictive models as reliable operational
    predictors.
-   Do not interpret historical elapsed gaps as causal effects or
    verified savings.
-   Do not present synthetic experiment outputs as historical
    intervention results.
-   Review data rights, privacy, export contents, and repository history
    before publishing.
-   The current local single-user prototype does not provide enterprise
    authentication, multi-user access control, or production operational
    safeguards.

## Project status

Veylora is an actively developed local research and portfolio prototype.
The eight workspaces and the initial tool-using optimization workflow
are implemented. Further work remains in data validation,
reproducibility, predictive model quality, causal study design, security
verification, and deployment readiness.
