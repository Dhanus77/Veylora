# Processed Data

This directory contains the processed CSV artifacts used by Veylora.

The application loads 23 configured analytical artifacts through
src/flowlens/catalog.py.

These files are derived analytical outputs from the BPI Challenge 2017
event log. They are not the original raw event log.

The original XML event logs are intentionally excluded from this repository
because of their size. Refer to data/raw/README.md for dataset provenance.

Synthetic experiment outputs must be interpreted separately from
historical observational findings.
